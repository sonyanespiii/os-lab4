# Отчет о проведении тестирования

## 1\. Цель тестирования

Проверка корректности работы скриптов `main.sh`, `attendance.sh`, `surname.sh`, `dossier.sh` в соответствии с функциональными требованиями лабораторной работы №4.

**Критерии успешности:**

* Все базовые команды возвращают корректный результат
* Ошибки ввода обрабатываются без падения скрипта
* Граничные случаи не приводят к некорректному выводу
* Уязвимости исключены

## 2\. Методика тестирования

**Фреймворк:** `run\_tests.sh` — собственный скрипт автоматизированного тестирования.

**Принцип работы:**

1. Скрипт находит все файлы в директории `tests/`
2. Из каждого файла извлекается команда (`COMMAND:`) и ожидаемый вывод (`EXPECT:`)
3. Команда выполняется через `bash -c`
4. Фактический вывод сравнивается с ожидаемым
5. Результат: `PASS` или `FAIL`

**Формат тестового файла:**

```
COMMAND: ./main.sh --group A-09-23 --sort attendance
EXPECT:
LitvichenkoYD 18 посещений
IvashutaYA 15 посещений
```

**Запуск:**

```
./run\_tests.sh
```
