# СТРУКТУРА ДАННЫХ ДЛЯ ЛАБОРАТОРНОЙ РАБОТЫ N4

## 1. ОБЩИЕ ПОЛОЖЕНИЯ

Настоящий документ описывает структуру исходных данных, используемых в рамках лабораторной работы N4. Данные представляют собой файловую систему преподавателя из лабораторной работы N3 и расположены в директории `data/`.

**Структура директории `data/`:**

```
data/
├── Пересдачеведение/
│   ├── tests/
│   │   ├── TEST-1
│   │   ├── TEST-2
│   │   ├── TEST-3
│   │   └── TEST-4
│   └── A-XX-YY-attendance
├── Цирковое_Дело/
│   ├── tests/
│   │   ├── TEST-1
│   │   ├── TEST-2
│   │   ├── TEST-3
│   │   └── TEST-4
│   └── A-XX-YY-attendance
└── students/
    ├── general/notes/
    │   └── <ПерваяБуква>Names.log
    └── groups/
        └── A-XX-YY
```

**Предметы преподавателя:**
- Пересдачеведение
- Цирковое_Дело

## 2. ФАЙЛЫ РЕЗУЛЬТАТОВ ТЕСТИРОВАНИЯ (TEST-N)

**Расположение:** `data/<ПРЕДМЕТ>/tests/TEST-N`, где N — номер теста (1–4)

**Формат данных:** текстовый файл, разделитель полей — точка с запятой (`;`)

**Структура строки:**

| Поле | Содержимое | Пример |
|------|-----------|--------|
| 1 | Группа | `A-09-23` |
| 2 | ФИО студента | `LitvichenkoYD` |
| 3 | Дата | `2026-11-03` |
| 4 | Количество правильных ответов | `5` |
| 5 | Оценка (может содержать модификаторы `+` или `-`) | `5`, `4+`, `2-` |

**Пример записи:**

```
A-09-23;LitvichenkoYD;2026-11-03;5;5
```

**Назначение данных:**
- Результаты тестирования по предмету
- Основа для расчёта среднего балла студента
- Основа для определения задолженностей (оценки 1 и 2)

## 3. ФАЙЛЫ УЧЕТА ПОСЕЩАЕМОСТИ (ATTENDANCE)

**Расположение:** `data/<ПРЕДМЕТ>/A-XX-YY-attendance`, где `A-XX-YY` — идентификатор группы

**Формат данных:** текстовый файл, каждая строка содержит информацию о посещаемости одного студента

**Структура строки:**

| Поле | Содержимое | Разделитель |
|------|-----------|-------------|
| 1 | ФИО студента | Пробел |
| 2 | Последовательность символов `0` и `1` | — |

**Обозначения в последовательности:**
- `1` — студент присутствовал на занятии
- `0` — студент отсутствовал на занятии
- Позиция символа в строке соответствует номеру занятия (1-е занятие, 2-е занятие и т.д.)
- Длина последовательности соответствует общему количеству занятий по предмету

**Пример записи:**

```
LitvichenkoYD 111111111111111111
```

Данная запись означает, что студент `LitvichenkoYD` присутствовал на всех 18 занятиях.

**Пример записи с пропусками:**

```
PashkovskyA 101000011101001110
```

Данная запись означает, что студент `PashkovskyA` пропустил занятия с номерами 2, 4, 5, 6, 7, 11, 13, 14, 17.

**Назначение данных:**
- Определение количества посещений студента (подсчёт символов `1`)
- Определение пропущенных занятий (позиции символов `0`)
- Вывод номеров пропущенных занятий по каждому предмету отдельно

## 4. ДОСЬЕ СТУДЕНТОВ (*NAMES.LOG)

**Расположение:** `data/students/general/notes/<ПерваяБуква>Names.log`

**Формат данных:** текстовый файл, содержащий характеристики студентов, составленные преподавателем. Файлы распределены по алфавиту — каждый файл содержит характеристики студентов, чья фамилия начинается с соответствующей буквы.

**Примеры файлов:**
- `ANames.log` — студенты на букву «A»
- `BNames.log` — студенты на букву «B»
- ...
- `LNames.log` — студенты на букву «L»
- ...
- `ZNames.log` — студенты на букву «Z»

**Структура записи:**

| Элемент | Содержимое |
|---------|-----------|
| Строка 1 | ФИО студента (точное совпадение с именем в группе) |
| Строка 2 | Текст характеристики студента |

**Пример записи:**

```
LitvichenkoYD
Старательная студентка, всегда выполняет задания.
```

**Назначение данных:**
- Формирование раздела «Характеристика» в досье студента
- Вывод текстовой характеристики, составленной преподавателем

## 5. СПИСКИ ГРУПП

**Расположение:** `data/students/groups/A-XX-YY`, где `A-XX-YY` — идентификатор группы

**Формат данных:** текстовый файл, каждая строка содержит ФИО одного студента

**Пример записей:**

```
LitvichenkoYD
LoginovVz
LoginovA
Surovtsev-ButovA
```

**Назначение данных:**
- Определение состава студентов группы
- Основа для сортировки по посещаемости
- Основа для поиска студента с максимальной длиной фамилии

### 5.1. Определение самой длинной фамилии

**Требование:** при определении самой длинной фамилии в группе учитывается **только длина фамилии без инициалов** (какие бы они ни были).

**Правило извлечения фамилии:**
- Фамилия — это часть ФИО от начала строки до первых инициалов
- Дефисные фамилии учитываются целиком (например, `Surovtsev-Butov` из `Surovtsev-ButovA`)
- Инициалы (одна или несколько заглавных букв в конце записи) не учитываются

**Примеры извлечения фамилии:**

| ФИО в файле группы | Фамилия | Длина фамилии |
|--------------------|---------|---------------|
| `LitvichenkoYD` | `Litvichenko` | 11 |
| `LoginovVz` | `Loginov` | 7 |
| `Surovtsev-ButovA` | `Surovtsev-Butov` | 15 |
| `LoginovA` | `Loginov` | 7 |
| `YurkovaSM` | `Yurkova` | 7 |

**Формат вывода команды:**

```
Студент: <полное ФИО из файла группы>
Фамилия: <извлечённая фамилия> (длина: <N> символов)
```

**Пример вывода:**

```
Студент: Surovtsev-ButovA
Фамилия: Surovtsev-Butov (длина: 15 символов)
```

## 6. ПРЕДМЕТЫ ПРЕПОДАВАТЕЛЯ

В рамках лабораторной работы используются данные по двум учебным дисциплинам:

| Предмет | Директория |
|---------|-----------|
| Пересдачеведение | `data/Пересдачеведение/` |
| Цирковое_Дело | `data/Цирковое_Дело/` |

**Каждый предмет включает:**
- Четыре файла с результатами тестирования (`tests/TEST-1` ... `tests/TEST-4`)
- Файлы учёта посещаемости (`A-XX-YY-attendance` для каждой группы)

## 7. ФОРМАТЫ ВЫВОДА КОМАНД

### 7.1. Вывод списка группы, отсортированного по посещаемости

**Назначение:** вывод списка студентов группы в порядке убывания количества посещений.

**Логика подсчёта:**
- Для каждого студента группы подсчитывается количество символов `1` в строке посещаемости
- Результат сортируется по убыванию количества посещений

**Формат вывода:**

```
<ФИО студента> <количество посещений> посещений
```

**Пример вывода:**

```
LitvichenkoYD 18 посещений
IvashutaYA 15 посещений
DavydovaYP 15 посещений
SharapovMN 14 посещений
```

### 7.2. Формирование досье студента

**Назначение:** формирование полного отчёта о студенте, включающего характеристику, пропуски, успеваемость и задолженности.

**Общий формат вывода:**

```
=== ДОСЬЕ СТУДЕНТА: <ФИО> ===

[Характеристика]
<текст характеристики или "Отсутствует.">

[Пропуски]
<раздельный вывод по предметам или "Пропусков не зафиксировано.">

[Успеваемость]
<средний балл или "Средний балл: нет данных">

[Задолженности]
<раздельный вывод по предметам с указанием тестов или "Задолженности: нет">
```

#### 7.2.1. Раздел «Характеристика»

- Выводится текст характеристики из досье студентов
- Если характеристика для студента не найдена — выводится «Отсутствует.»

#### 7.2.2. Раздел «Пропуски» (раздельно по предметам)

**Требование:** пропуски занятий выводятся **по каждому предмету отдельно** с указанием номеров пропущенных занятий.

**Логика формирования:**
- Для каждого предмета находится строка посещаемости студента
- Определяются позиции символов `0` в последовательности (это номера пропущенных занятий)
- Номера выводятся через запятую для каждого предмета отдельной строкой

**Формат вывода:**

```
[Пропуски]
Цирковое_Дело: 1, 3, 5, 7, 8, 9
Пересдачеведение: 4, 5, 6, 7, 9, 15
```

**Правила вывода:**
- Если по предмету пропусков нет — строка по этому предмету не выводится
- Если пропусков нет ни по одному предмету — выводится «Пропусков не зафиксировано.»

**Пример при отсутствии пропусков:**

```
[Пропуски]
Пропусков не зафиксировано.
```

#### 7.2.3. Раздел «Успеваемость»

**Логика формирования:**
- Собираются все оценки студента по всем тестам всех предметов
- Модификаторы `+` и `-` отбрасываются, остаётся только числовое значение
- Вычисляется сумма и количество оценок
- Средний балл вычисляется как сумма, делённая на количество

**Формат вывода:**

```
[Успеваемость]
Средний балл: <X.XX> (всего оценок: <N>, сумма: <S>)
```

**Пример вывода:**

```
[Успеваемость]
Средний балл: 2.67 (всего оценок: 3, сумма: 8)
```

**При отсутствии оценок:**

```
[Успеваемость]
Средний балл: нет данных
```

#### 7.2.4. Раздел «Задолженности» (с указанием тестов)

**Требование:** при выводе задолженностей необходимо указывать, **по каким именно тестам** эти задолженности возникли. Вывод осуществляется **по каждому предмету отдельно**.

**Логика формирования:**
- Задолженностью считается оценка `0`, `1` или `2` (с возможными модификаторами `+`/`-`) в файле теста
- Для каждого предмета проверяются все четыре теста (`TEST-1` ... `TEST-4`)
- Если в тесте найдена задолженность, в вывод добавляется номер теста в формате «тест №N»
- Тесты выводятся через запятую для каждого предмета отдельной строкой

**Формат вывода:**

```
[Задолженности]
Цирковое_Дело: тест №1, тест №4
Пересдачеведение: тест №2
```

**Правила вывода:**
- Если по предмету задолженностей нет — строка по этому предмету не выводится
- Если задолженностей нет ни по одному предмету — выводится «Задолженности: нет»

**Пример при отсутствии задолженностей:**

```
[Задолженности]
Задолженности: нет
```

### 7.3. Полный пример вывода досье

**Пример для студента с пропусками и задолженностями:**

```
=== ДОСЬЕ СТУДЕНТА: PashkovskyA ===

[Характеристика]
Клонит в сон от его храпа. Ничего не записывает. Делает сэлфи на каждой лекции. Подлизывается, это можно использовать!

[Пропуски]
Пересдачеведение: 14
Цирковое_Дело: 2, 4, 5, 6, 7, 11, 13, 14, 17

[Успеваемость]
Средний балл: 2.67 (всего оценок: 3, сумма: 8)

[Задолженности]
Пересдачеведение: тест №1
Цирковое_Дело: тест №1
```

**Пример для отличника без пропусков и задолженностей:**

```
=== ДОСЬЕ СТУДЕНТА: LitvichenkoYD ===

[Характеристика]
Отличник. Посещает все занятия. Активно участвует в обсуждениях. Помогает одногруппникам.

[Пропуски]
Пропусков не зафиксировано.

[Успеваемость]
Средний балл: 4.38 (всего оценок: 8, сумма: 35)

[Задолженности]
Задолженности: нет
```
