1.ОБЩИЕ ПОЛОЖЕНИЯ

Настоящий документ описывает структуру исходных данных, используемых в рамках лабораторной работы N4. Данные представляют собой файловую систему преподавателя из лабораторной работы N3 и расположены в директории data/.

Структура директории data/:

data/
  Пересдачеведение/
    tests/
      TEST-1, TEST-2, TEST-3, TEST-4
    A-XX-YY-attendance
  Цирковое дело/
    tests/
      TEST-1, TEST-2, TEST-3, TEST-4
    A-XX-YY-attendance
  students/
    general/notes/LNames.log
    groups/A-XX-YY

2.ФАЙЛЫ РЕЗУЛЬТАТОВ ТЕСТИРОВАНИЯ (TEST-N)

Расположение: data/<ПРЕДМЕТ>/tests/TEST-N
Пример: data/Пересдачеведение/tests/TEST-1

Формат данных: текстовый файл, разделитель полей - точка с запятой (;)

Структура строки:
<группа>;<ФИО>;<дата>;<количество правильных ответов>;<оценка>

Пример строки:
A-09-23;LitvichenkoYD;2026-11-03;5;5

Описание полей:
Поле 1: Группа (строка, формат A-XX-YY, например A-09-23)
Поле 2: ФИО (строка, фамилия и инициалы, например LitvichenkoYD)
Поле 3: Дата (формат YYYY-MM-DD, например 2026-11-03)
Поле 4: Количество правильных ответов (целое число)
Поле 5: Оценка (строка, может содержать модификаторы + или -, например 5, 4+, 2-)

Извлечение ФИО (второе поле) через sed:
sed -E 's/^[^;];([^;]);./\1/' data/Пересдачеведение/tests/TEST-1
(Регулярное выражение: ^[^;]; - первое поле и разделитель,
([^;]) - второе поле в скобках, ;. - остальная строка,
\1 - выводим только второе поле)

Поиск всех записей конкретного студента:
grep "LitvichenkoYD" data/Пересдачеведение/tests/TEST-*

Фильтрация успешных попыток (оценка 3, 4 или 5):
grep -E ";[345][+-]*$" data/Пересдачеведение/tests/TEST-1

Фильтрация неуспешных попыток (оценка 1 или 2):
grep -E ";[12][+-]*$" data/Пересдачеведение/tests/TEST-1

Извлечение только оценок (пятое поле) через sed:
sed -E 's/.*;([^;]+)$/\1/' data/Пересдачеведение/tests/TEST-1

Подсчет количества попыток студента:
grep -c "LitvichenkoYD" data/Пересдачеведение/tests/TEST-1

3.ФАЙЛЫ УЧЕТА ПОСЕЩАЕМОСТИ (ATTENDANCE)

Расположение: data/<ПРЕДМЕТ>/A-XX-YY-attendance
Пример: data/Пересдачеведение/A-09-23-attendance

Формат данных:
Каждая строка содержит информацию о посещаемости одного студента.

Структура строки:
<ФИО> <последовательность символов 0 и 1>

Пример:
LitvichenkoYD 11111111111111111111111111111111111111111111111111
LoginovVz 10101010101010101010101010101010101010101010101010

Описание полей:
Поле 1: ФИО (строка, разделитель - пробел)
Поле 2: Последовательность символов
(1 = студент присутствовал, 0 = студент отсутствовал)

Методы обработки данных:

Получение данных о посещаемости конкретного студента:
grep "LitvichenkoYD" data/Пересдачеведение/A-09-23-attendance

Подсчет количества посещений (символов "1"):
grep "LitvichenkoYD" data/Пересдачеведение/A-09-23-attendance | grep -o "1" | wc -l

Подсчет количества пропусков (символов "0"):
grep "LitvichenkoYD" data/Пересдачеведение/A-09-23-attendance | grep -o "0" | wc -l

4.ДОСЬЕ СТУДЕНТОВ (LNAMES.LOG)

Расположение: data/students/general/notes/LNames.log

Формат данных:
Файл содержит характеристики студентов, составленные преподавателем.

Структура записи:
<ФИО>
<текст характеристики>
======================

Пример:
LitvichenkoYD
Старательная студентка, всегда выполняет задания.

Методы обработки данных:

Извлечение характеристики конкретного студента:
grep -A 1 "LitvichenkoYD" data/students/general/notes/LNames.log
(Опция -A 1 выводит одну строку после найденного совпадения)

Проверка наличия студента в досье:
grep -c "LitvichenkoYD" data/students/general/notes/LNames.log

5.СПИСКИ ГРУПП

Расположение: data/students/groups/A-XX-YY
Пример: data/students/groups/A-09-23

Формат данных:
Файл содержит список ФИО студентов группы, по одному имени на строку.

Пример:
LitvichenkoYD
LoginovVz
LoginovA

Методы обработки данных:

Вывод списка группы:
cat data/students/groups/A-09-23

Подсчет количества студентов в группе:
wc -l < data/students/groups/A-09-23

Сортировка списка группы по алфавиту:
sort data/students/groups/A-09-23

Поиск студента с максимальной длиной фамилии:
cat data/students/groups/A-09-23 | while read name; do len=$(echo -n "$name" | wc -c) 
echo "$len $name" 
done | sort -rn | head -1 | sed 's/^[0-9]* //'
(Алгоритм: для каждой фамилии вычисляется длина строки через wc -c, результат выводится в формате "длина фамилия", сортируется по убыванию, берется первая строка, через sed удаляется число в начале)

Проверка принадлежности студента к группе:
grep -c "LitvichenkoYD" data/students/groups/A-09-23

6.ПРЕДМЕТЫ ПРЕПОДАВАТЕЛЯ

В рамках текущей лабораторной работы используются данные по двум учебным дисциплинам:

Каждый предмет включает:
Четыре файла с результатами тестирования (tests/TEST-1 ... tests/TEST-4)

Для получения данных по всем предметам одновременно используется шаблон:
data/*/tests/TEST-*
data/*/A-XX-YY-attendance

7.ПРИМЕРЫ РЕАЛИЗАЦИИ ФУНКЦИОНАЛЬНЫХ ТРЕБОВАНИЙ

7.1. Вывод списка группы, отсортированного по посещаемости

Команда:
cat data/students/groups/A-09-23 | while read student; do count=$(grep "$student" data/Пересдачеведение/A-09-23-attendance | grep -o "1" | wc -l)
echo "$count $student"
done | sort -rn

Описание алгоритма:
1.Считывается список студентов из файла группы (cat + while read)
2.Для каждого студента командой grep ищется строка в файле
посещаемости
3.grep -o "1" выделяет все символы "1", wc -l их считает
4.Выводится результат в формате: <количество посещений> <ФИО>
5.Результаты сортируются по убыванию (sort -rn)

7.2. Вывод студента с максимальной длиной фамилии

Команда:
cat data/students/groups/A-09-23 | while read name; do len=$(echo -n "$name" | wc -c)
echo "$len $name"
done | sort -rn | head -1 | sed 's/^[0-9]* //'

Описание алгоритма:
1.Читается файл группы построчно (while read)
2.Для каждой фамилии вычисляется длина строки (wc -c)
3.Производится сортировка по убыванию длины (sort -rn)
4.Выбирается первая запись (head -1) - максимальная длина
5.Через sed удаляется число в начале строки, остаётся только фамилия

7.3. Формирование досье студента

1.Характеристика из досье:
grep -A 1 "ФамилияСтудента" data/students/general/notes/LNames.log

2.Количество пропущенных занятий:
grep "ФамилияСтудента" data/Пересдачеведение/A-XX-YY-attendance | grep -o "0" | wc -l

3.Список задолженностей (оценки 1 и 2):
grep "ФамилияСтудента" data/Пересдачеведение/tests/TEST-* | grep -E ";[12][+-]*$"

4.Расчет средней оценки (алгоритм для разработчика):
Шаг 1: Найти все строки студента во всех TEST-файлах с помощью grep.
Шаг 2: С помощью sed извлечь только 5-е поле (оценку), отбросив группу, ФИО и дату.
Шаг 3: С помощью sed удалить возможные модификаторы "+" и "-", оставив только цифры.
Шаг 4: Разработчик реализует логику суммирования полученных числовых значений и деления на их количество.

8.СПРАВОЧНАЯ ИНФОРМАЦИЯ

8.1. Используемые команды Linux

grep - поиск строк по шаблону в файлах
sed - потоковое редактирование и преобразование текста
sort - построчная сортировка данных
wc - подсчет строк, слов, символов
head - вывод первых строк файла
tail - вывод последних строк файла
cat - объединение и вывод содержимого файлов
echo - вывод текста в терминал
find - поиск файлов по мета-данным
xargs - передача списка файлов другой команде
vim - текстовый редактор
less - постраничный просмотр файлов

8.2. Специальные символы регулярных выражений

^ - начало строки
$ - конец строки
* - 0 или более повторений
+ - 1 или более повторений
? - 0 или 1 повторение
{n} - ровно n повторений
{n,m} - от n до m повторений
[] - класс символов
[^] - отрицание класса символов
. - любой символ
| - логическое ИЛИ (в расширенных регулярных выражениях)

8.3. Ключи используемых команд

grep:
-E - расширенные регулярные выражения
-c - подсчет количества совпадений
-o - вывод только совпавших частей строк
-A n - вывод n строк после совпадения
-B n - вывод n строк до совпадения
-i - нечувствительность к регистру
-r - рекурсивный поиск по директориям

sed:
s/шаблон/замена/ - режим замены
d - режим удаления
p - вывод на экран
g - глобальная замена (все вхождения в строке)
-E - расширенные регулярные выражения
-i - изменение файла на месте

sort:
-r - обратный порядок сортировки
-n - числовая сортировка
