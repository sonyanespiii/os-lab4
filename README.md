# Документация решения

## 1. Общие сведения

**Название проекта:** Система управления данными преподавателя (os-lab4)

**Назначение:** Автоматизация анализа успеваемости и посещаемости студентов на основе файловой системы преподавателя.

**Цели разработки:**
- Реализовать базовые команды работы с группой (сортировка по посещаемости, поиск максимальной фамилии)
- Реализовать формирование полного досье студента
- Обеспечить корректную обработку ошибок и валидацию входных данных
- Покрыть функциональность автоматизированными тестами

**Предметная область:** Файловая система преподавателя из лабораторной работы №3, содержащая списки групп, журналы посещаемости, результаты тестирования и характеристики студентов по двум дисциплинам: «Пересдачеведение» и «Цирковое_Дело».

## 2. Функциональные требования

### Перечень команд

| Команда | Назначение |
|---------|-----------|
| `--group <ID> --sort attendance` | Вывод списка группы по убыванию посещаемости |
| `--group <ID> --max-surname` | Вывод студента с максимальной длиной фамилии |
| `--student <ФИО> --dossier` | Формирование полного досье студента |
| `--help` | Вывод справки по всем командам |

### Входные данные

- Идентификатор группы (формат: `A-XX-YY` или `Ae-XX-YY`)
- ФИО студента (формат: `ФамилияИО`, латиница)

### Выходные данные

- Для `--sort attendance`: список студентов с количеством посещений, отсортированный по убыванию
- Для `--max-surname`: имя студента и длина фамилии
- Для `--dossier`: характеристика, номера пропусков по предметам, средний балл, задолженности

## 3. Описание команд и примеры использования

### Сортировка группы по посещаемости

```
./main.sh --group A-09-23 --sort attendance
```

**Вывод:**

```
LitvichenkoYD 18 посещений
IvashutaYA 15 посещений
DavydovaYP 15 посещений
SharapovMN 14 посещений
```

### Поиск студента с максимальной фамилией

```
./main.sh --group A-09-23 --max-surname
```

**Вывод:**

```
Студент: LevshchanovB
Фамилия: Levshchanov (длина: 11 символов)
```

### Формирование досье студента

```
./main.sh --student SharapovMN --dossier
```

**Вывод:**

```
=== ДОСЬЕ СТУДЕНТА: SharapovMN ===

[Характеристика]
Говорит Питон вместо Пайтон. Хорошо списывает! Пишет спагетти-код. ПЕЧАТАЕТ КАПСОМ. Некорректно использует * в сообщениях. Не экранирует специальные символы. 

[Пропуски]
Пересдачеведение: 6 11 13 17
Цирковое_Дело: 1 9 11 14

[Успеваемость]
Средний балл: 2.76 (всего оценок: 17, сумма: 47)

[Задолженности]
Пересдачеведение: тест №1, тест №3, тест №4
Цирковое_Дело: тест №1, тест №2, тест №4
```

### Справка

```
./main.sh --help
```
